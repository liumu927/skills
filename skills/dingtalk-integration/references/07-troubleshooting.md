# 排错总表

按现象查。每条给"原因 → 验证 → 解决"。一次只改一个变量，改完走发布链再复测。

## 先要三样东西

排错前先让用户提供其一，避免空对空：

1. 完整报错文本（不要只给截图标题）；
2. 执行详情 → 入参 → "复制"的 JSON；
3. 相关配置页截图（鉴权设置第 2/3 步、动作入参、表单映射）。

## 鉴权与 Token

| 现象 | 原因 | 验证 | 解决 |
|---|---|---|---|
| 授权页 `client_id is blank` | 授权接口只填了裸地址，没配查询参数 | 看 B2 第 3 步授权接口的 URL 查询参数网格 | 地址裸填，参数在网格逐行填 |
| 授权页 `应用不存在`(900103) | 无网页应用能力 / 回调未登记 / 未发版 | 看应用能力、安全设置、版本状态 | 三项补齐并发版 |
| 授权页 redirect_uri 错误 | 网格里填了预编码值，平台又编码一次 | 看参数值是否含 `%3A%2F%2F` | 改填裸地址 |
| Token 接口 `MissingappKey: appKey is mandatory` | 钉钉只认 JSON body，平台默认未按 JSON 发 | 看接口是否配了 Content-Type | 获取/刷新接口各加 `Content-Type: application/json` |
| `fetch_token_result_not_mapping_config`，**刚配完正常、过段时间起持续报** | 刷新 Token 的 appKey/appSecret 误填在"HTTP 请求头" | 看刷新接口参数所在分类 | 两行移回**请求体** + 补 Content-Type → 发布 → 临时把刷新周期调 300 秒，连续 2~3 次刷新成功再调回 5400 |
| `fetch_token_result_not_mapping_config` / appKey is mandatory，**配完就报、重新授权也报** | 连接平台回调地址变了，与应用安全设置不一致 | 对比连接平台第 2 步回调与应用重定向 URL | 复制最新回调 → 更新应用重定向 URL → 发版 → 重新添加账户授权 |
| 保存鉴权提示"较大变动"，凭证变灰 | 平台机制：鉴权大改会把已授权账户标记为待更新 | 看凭证旁是否显示"更新账户" | 点"更新账户"重新授权；弹窗被拦就在自己浏览器打开授权链接 |
| 授权回调页 `ERR_NAME_NOT_RESOLVED` | 内置浏览器 DNS 抖动，授权码已送达 | 刷新连接器页看凭证状态 | 不影响结果；反复出现就换浏览器操作 |
| `AuthenticationFailed.MissingParameter: 缺少 x-acs-dingtalk-access-token` | 鉴权未配置/凭证未添加 | 看鉴权设置与账户列表 | 完成 OAuth2.0 五步 + 添加账户 |
| 401 ExpiredAccessToken 偶发 | 失效判断只配了 400 | 看自动刷新配置 | 加一条 401 兜底 |

## 多维表读写

| 现象 | 原因 | 验证 | 解决 |
|---|---|---|---|
| 403 permission deny | 文档是个人文档 / 应用无读权限 / 未发版 | 三道门逐个查 | 文档共享给组织；开通 Notable 读权限；发版 |
| `InvalidRequest.ResourceNotFound: identifier 'xxx'` | 填成了文档名；或中文表名编码问题（报错标识符是乱码） | 看入参 sheetIdOrName | 用表 ID（`GET /sheets` 查） |
| `InvalidArgument: operator 'null' is invalid for field` | "条件"里只有字段名，没有操作符/值 | 看 filter 结构 | 条件要么三要素齐全，要么整个留空；"字段"参数才是控制返回列的 |
| 每次获取记录数报错 | maxResults 超上限 | 看入参 | 填 100 |
| `JSON Array parsing error`(InvalidConditions) | `conditions` 声明成 object 多套一层 Items | 看 API 入参结果 | 改平为 array → 子项 `{field, operator, value(array)}` |
| `Missingfield: field is mandatory` | 结构改平后子项映射丢失 | 看调试页"API 入参结果" | 补齐 field/operator/value 三个映射 |
| `condition value should be an array` | 查询值（如 sn）为空，序列化时被丢弃 | 看入参实际值 | 换当前表单真实编码；确认值非空 |
| `fail to find field 'TextField_xxx'` | `fields` 的键用了审批编码，接口只认表格列名 | 看 fields 键 | 键改表格列头，一字不差 |
| `fail to find field 'unionId'` | 键写成了参数名 | 同上 | 键=列头，参数名只能出现在值里 |
| `fields_error`（人员列） | 传了裸字符串或字符串数组 | 看 fields 值 | `[{"unionId":"..."}]` 对象数组 |
| 人员格式对了还不认 | unionId / userId 混用 | 看用的哪套 ID | 直连 API 用 unionId 对象数组；官方槽位填 userId 字符串 |
| `fields_error`（其余列全对，新加列报错） | 新列值结构不对 | 二分法：只留嫌疑字段跑一轮 | 下拉取 `.label`；日期截前 10 位 |
| 写入日期 +1 天 | 假 Z 被按 UTC 解析 | 看源时间与落库日期 | `LEFT(时间,10)` 存文本列 |
| 某列为空 / 接口收不到某参数（**无报错**） | 自定义连接器开了"入参映射"但没配规则 | 看映射规则列表 | 配齐映射 |

## 表单与流程

| 现象 | 原因 | 验证 | 解决 |
|---|---|---|---|
| 回填报"单选组件值列表、ID 列表长度应该一致" | 只映射了值列表 | 看两行映射 | 两行都映射 |
| 下拉选项为空但无报错 | 映射没配 / 未发布 / 触发条件未满足 | 逐项查 | 补映射、发布模板、用"新建表单加载时" |
| 出参映射里找不到字段值，只有记录ID/游标 | 用了官方 AI 表格连接器 | 看连接器类型 | 自建 HTTP 连接器，导入真实 JSON 声明出参 |
| 关联应用下拉"暂无数据" | 平台 bug | — | 用 OAuth2.0 凭证方案绕过 |
| 动态出参开关打开了，表单映射不到 | 高级设置未关 | 看连接器高级设置 | 关闭动态出参 |
| 回显文本控件空白 | 没取数组第一项 / 条件三要素不全 / 表里无匹配 | 逐项查 | `records[0]`；条件引用控件；核对数据 |
| 联系人控件收不到数据 | 平台限制：按 userId 定位，表里是 unionId；表单级不能链式 | — | 改两文本控件回显 + 流程节点转换 |
| 审批节点取不到人/派不出去 | 直接把 unionId 给了节点 | 看节点负责人来源 | 走通讯录连接器换 userId |
| 节点报"未找到审批人" | unionId 查不到：离职/非本企业/填错 | 用"查询用户详情"核对 | 更新表内负责人；离职交接加"同步更新"步骤 |
| 审批人派错人 | 项目名重复，取第一条匹配 | 查表内是否同名 | 唯一性治理；加第二字段联合过滤 |
| 发起人手改控件改了审批人 | 文本控件默认可编辑 | 看字段权限 | 设为只读 |
| 初始加载就报错 | 触发条件用了"新建表单加载时"而依据控件为空 | 看触发条件 | 改"控件值发生变化时"+ 必填 |
| 配置改了没生效 | 发布链断了 | 看动作/连接器/模板发布状态 | 动作发布 → 连接器发布 → 模板发布 |

## 连接流与循环

| 现象 | 原因 | 验证 | 解决 |
|---|---|---|---|
| 循环跑 N 次都处理第一条 | 循环内容选到了 `.字段`（无 id），或循环体内引用固定下标 | 循环节点入参是否有 id；切换循环执行次数看是否恒定 | 循环内容上移到 `记录[*]`；体内引用循环当前项 |
| 循环只跑一次 | 下标选成 `[1]` 而非 `[*]` | 看循环内容 | 保持 `[*]` |
| 表里出现多条同样数据 / 一格塞数组 | 引用了整个数组，数组语义是聚合 | 看引用的是否 `[*]` | 逐条写入走循环项 |
| 循环项展不开，只能选整个对象 | 循环项是无结构 object | — | 整对象传给连接器后端映射；或 chip+原始编码 |
| 表达式取值为空 | 用了中文显示名 | 看表达式 | 改原始编码 |
| 表达式整体退化成文本 | 对象键用双引号 / 多行 | 看预览是否显示对象形态 | 单引号键、压一行 |
| 循环内计量偏高 | 循环内子节点均计量 | 看执行记录 | 判重不可避免；写入精简；评估批量规模 |
| 超过 100 条后不动 | pageSize/循环条数上限 | 看是否有 nextCursor | 分页或分批 |
| 更新节点报无目标记录 | 更新目标沿用了上游出参 id，上游查空 | 看更新目标引用 | 改循环当前项.id |

## 报错决策树（速查）

```
403 permission deny
  → 文档共享 + 应用权限 + 发版

ResourceNotFound identifier='<文档名或乱码>'
  → 用表 ID（GET /sheets 查）

operator 'null' is invalid
  → 条件留空，或补齐字段+操作符+值

MissingParameter / 401
  → 凭证存在？鉴权是 OAuth2.0 且已保存？

fetch_token_result_not_mapping_config
  → 配完正常、过段时间才报：刷新接口参数误填在请求头（移回请求体）
  → 配完就报：回调地址与应用安全设置不一致（更新重定向 URL + 发版 + 重新授权）

redirect_uri 相关
  → 网格里填了预编码值（改裸地址）

值列表/ID列表长度不一致
  → 补 ID 列表映射

联系人控件收不到数据
  → 平台限制，改文本控件 + 流程节点转换

审批节点取不到人
  → 走通讯录连接器 unionId→userId

循环都处理第一条
  → 循环内容选整条记录；体内引用循环当前项

新增多条重复 / 一格塞数组
  → 引用了整个数组（聚合），改走循环项

某列为空但无报错
  → 入参映射规则没配齐

fail to find field 'X'
  → 键改表格列头

fields参数格式不正确
  → 人员列用对象数组；下拉取 label；日期 LEFT(,10)；表达式单引号压一行

condition value should be an array
  → 查询值为空，换表单真实编码
```
